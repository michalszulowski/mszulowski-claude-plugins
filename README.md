# mszulowski-claude-plugins

Skille do Claude Code.

## Instalacja (Linux)

Plugin:

```bash
claude plugin marketplace add michalszulowski/mszulowski-claude-plugins
claude plugin install mszulowski@mszulowski-plugins
```

Automatyczne aktualizacje włączasz w Claude Code: `/plugin` → Marketplaces → `mszulowski-plugins` → Enable auto-update.
